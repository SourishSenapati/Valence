# OpenProcessSim

An open-source, lightweight, agent-native chemical process simulator built in Python.

## Features

- **Deterministic & Zero-Hallucination:** Rigorous physical properties derived from open scientific databases (NIST, DIPPR, `chemicals`).
- **Agent-Ready:** Clean Python data models, JSON schemas, and automatic Markdown stream reporting.
- **Ultra-Lightweight:** Instant install, cross-platform, zero proprietary bloat.

## Quickstart

```bash
uv pip install -e .
python demo.py
```
